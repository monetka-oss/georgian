# Шпаргалка по живому грузинскому языку и тбилисскому сленгу

Эта таблица собрана на основе нашего разбора: здесь есть и бытовые фразы, и грамматические связки, и уличный базар, и правила поведения на застолье (супре).

| Категория | Выражение / Слово | Транскрипция | Перевод / Смысл | Пример использования / Контекст |
| :--- | :--- | :--- | :--- | :--- |
| **Быт и поиск** | თვის გადასახადი | *tvis gadasakhadi* | Оплата за месяц / ежемесячный платёж | კომუნალურების **თვის გადასახადი** (*komunalurebis tvis gadasakhadi* — оплата комуналки за месяц) |
| | არა, მოიცა, მე თვითონ ვიპოვი ეგეთი | *ara, moitsa, me tviton vipovi egeti* | Не, погоди, я сам такой же найду | Используй, когда тебе предлагают вариант, а ты хочешь найти дешевле или лучше сам |
| | ახლავე ვიპოვი | *akhlave vipovi* | Сейчас же найду | **ახლავე ვიპოვი** ტელეფონში (*akhlave vipovi telefonshi* — Сейчас же найду в телефоне) |
| **Грамматика и связки** | რახან | *rakhan* | Раз уж / поскольку | **რახან** აქ ხარ, ბარემ მომეხმარე (*rakhan ak khar, barem momekhmare* — Раз уж ты здесь, заодно помоги) |
| | ბარემ | *barem* | Заодно / раз пошла такая пьянка | მაღაზიაში მივდივარ და **ბარემ** პურსაც ვიყიდი (*...da barem pursats viqidi* — Иду в магазин и заодно хлеба куплю) |
| | ვითომ | *vitom* | Якобы / типа / будто бы | **ვითომ** არ იცოდი (*vitom ar itsodi* — Типа ты не знал) |
| | ხოლმე | *kholme* | Частица регулярности («бывает», периодически) | აქ ხშირად მოვდივარ **ხოლმე** (*ak khshirad movdivar kholme* — Я сюда частенько захожу) |
| | თორემ | *torem* | А то / иначе | დროზე ქენი, **თორემ** დაგვაგვიანდება (*droze keni, torem dagvagviandeba* — Делай быстрее, а то опоздаем) |
| | შემთხვევით ხომ არ იცი... | *shemtkhvevit khom ar itsi...* | Ты случайно не знаешь... | **შემთხვევით ხომ არ იცი**, სად არის ეს ქუჩა? (*...sad aris es kucha?* — Случайно не знаешь, где эта улица?) |
| | არ / ვერ | *ar / ver* | Не (просто отказ) / Не могу (нет возможности) | **არ** ვაკეთებ (не делаю) vs **ვერ** ვაკეთებ (не могу сделать) |
| **База и реакции** | რა არის? (რარის?) | *ra aris? (raris?)* | Что такое? / Чего? | **რა არის**, რა ხდება? (*ra aris, ra khdeba?* — Чего такое, что происходит?) |
| | არაუშავს | *araushavs* | Ничего страшного / без проблем / проехали | — ბოდიში! — **არაუშავს**, ძმაო (*— Извини! — Без проблем, брат*) |
| | წავედით | *tsavedit* | Погнали / пошли | აბა, **წავედით**! (*aba, tsavedit!* — Ну, погнали!) |
| | მოკლედ | *mokled* | Короче говоря / в общем | **მოკლედ**, ასეთი სიტუაციაა (*mokled, aseti situatsiaa* — Короче, такая ситуация) |
| | მეზარება | *mezareba* | Мне лень / влом | დღეს გარეთ გასვლა **მეზარება** (*dghes garet gasvla mezareba* — Сегодня мне лень выходить на улицу) |
| | დაიკიდე | *daikide* | Забей болт / не парься | მაგაზე ნუ ინერვიულებ, **დაიკიდე** (*magaze nu inerviuleb, daikide* — Не нервничай насчёт этого, забей) |
| | სულ ერთია | *sul ertia* | Мне похер / без разницы | ჩემთვის **სულ ერთია** (*chemtvis sul ertia* — Для меня без разницы) |
| | მივხვდი | *mivkhvdi* | Понял / дошло | კაი, **მივხვდი**, აღარ გააგრძელო (*kai, mivkhvdi, aghar gaagrdzelo* — Ладно, понял, больше не продолжай) |
| | აბა, ჰე! | *aba, he!* | Всё, давай / пока | **აბა, ჰე**, ხვალამდე! (*aba, he, khvalamde!* — Ну давай, до завтра!) |
| **Тбилисский сленг** | ჩაგრავ / მიჩაგრავ | *chagrav / michagrav* | Душишь / грузишь / прессуешь (меня) | კაი რა, გაჩერდი, **ნუ მიჩაგრავ**! (*kai ra, gacherdi, nu michagrav!* — Да ладно, тормозни, не душни!) |
| | გავშტერდი | *gavshterdi* | Офигел / обалдел / ошарашен | რომ გავიგე, სულ **გავშტერდი** (*rom gavige, sul gavshterdi* — Когда узнал, вообще офигел) |
| | კაი ტიპი | *kai tipi* | Ровный, крутой, уважаемый в тусовке парень | მაგარი **კაი ტიპია**, გირჩევ გაიცნო (*magari kai tipia, girchev gaitsno* — Очень ровный тип, советую познакомиться) |
| | დაბოღმილი | *daboghmili* | Завистливый, злопамятный, набыченный | მაგას ნუ უსმენ, **დაბოღმილი** მასტია (*magas nu usmen, daboghmili mastia* — Его не слушай, он завистливый тип) |
| | კაი პონტია | *kai pontia* | Прикольная тема / хороший движ / вайб | მაგარი ადგილია, **კაი პონტია** (*magari adgilia, kai pontia* — Классное место, хороший вайб) |
| **Идиомы** | თავში ქვა იხალოს | *tavshi kva ikhalos* | Пусть камень о голову разобьёт (да пошёл он / мне плевать) | თუ არ უნდა, **თავში ქვა უხლია** (*tu ar unda, tavshi kva ukhlia* — Если не хочет, да и хрен с ним) |
| | ენაზე უკბინოს | *enaze ukbinos* | Прикусить язык (завалить и не болтать лишнего) | ჯობია **ენაზე იკბინოს** (*jobia enaze ikbinos* — Лучше бы ему прикусить язык) |
| | გული მომივიდა | *guli momivida* | Меня от этого воротит / взбесило | მაგის საქციელზე **გული მომივიდა** (*magis saktsielze guli momivida* — Меня аж взбесил его поступок) |
| **Осадить в споре** | ხმა ჩაიგდე! | *khma chaigde!* | Заткнись! / Засунь голос обратно! | **ხმა ჩაიგდე** და მომისმინე! (*khma chaigde da momismine!* — Заткнись и послушай меня!) |
| | შენ ვინ ეგონე თავს? | *shen vin egone tavs?* | Ты за кого себя вообще возомнил? | **შენ ვინ ეგონე თავს**, ეგრე რომ მელაპარაკები? (*...egre rom melaparakebi?* — Ты кем себя возомнил, что так со мной говоришь?) |
| | შენ შენს საქმეს მიხედე! | *shen shens sakmes mikhede!* | Занимайся своими делами! / Следи за собой! | ჩემს საქმეში ნუ ერევი, **შენ შენს საქმეს მიხედე!** (*chems sakmeshi nu erevi...* — В мои дела не лезь, следи за собой!) |
| | ტვინი არ მომწყვიტო! | *tvini ar momtsqvito!* | Не выноси мне мозг! | ერთი და იგივეს ნუ იმეორებ, **ტვინი არ მომწყვიტო!** (*erti da igives nu imeoreb...* — Не повторяй одно и то же, не выноси мозг!) |
| | რას ბოდიალობ, აზრზე ხარ? | *ras bodialob, azrze khar?* | Ты чё бредишь, ты вообще в адеквате? | რეებს იძახი, **რას ბოდიალობ, აზრზე ხარ?** (*reebs idzakhi...* — Что ты несёшь, ты вообще в курсе?) |
| | თუ რამე გაქვს სათქმელი, პირში მითხარი! | *tu rame gakvs satkmeli, pirshi mitkhari!* | Если есть что сказать — говори в лицо! | ზურგს უკან ნუ ლაპარაკობ, **პირში მითხარი!** (*zurgs ukan nu laparakob...* — За спиной не болтай, в лицо скажи!) |
| **Разрулить конфликт** | დავწყნარდეთ, კაცო! | *davtsqnardet, katso!* | Давай успокоимся, мужик / старик! | **დავწყნარდეთ, კაცო**, ნუ ვჩხუბობთ (*davtsqnardet, katso, nu vchkhubobt* — Давай успокоимся, дружище, не будем ссориться) |
| | მოდი, ნორმალურად ვილაპარაკოთ | *modi, normalurad vilaparakot* | Давай нормально поговорим | ყვირილს აზრი არ აქვს, **მოდი, ნორმალურად ვილაპარაკოთ** (*qvirils azri ar akvs...* — Кричать смысла нет, давай нормально поговорим) |
| | შენც მართალი ხარ რაღაც მხრივ, მარა... | *shents martali khar raghats mkhriv, mara...* | Ты в чём-то тоже прав, но... | Отличный дипломатический ход, чтобы сбить агрессию и перевести спор в конструктив |
| | ტყუილად ვცხარობთ | *tquilad vtskharobt* | Мы зря кипятимся / горячимся | **ტყუილად ვცხარობთ**, არ ღირს ამად (*tquilad vtskharobt, ar ghirs amad* — Зря горячимся, оно того не стоит) |
| | დავხურეთ ეს თემა | *davkhuret es tema* | Закрыли эту тему (точка) | მორჩა, **დავხურეთ ეს თემა** (*morcha, davkhuret es tema* — Всё, закрыли тему) |
| | მე ამაზე ლაპარაკის თავი არ მაქვს | *me amaze laparakis tavi ar makvs* | У меня нет настроения/желания об этом говорить | Жёсткий дипломатический съезд, после которого можно спокойно уйти |
| **Знакомства** | გამარჯობა, ძმაო! როგორ არის საქმეები? | *gamarjoba, dzmao! rogor aris sakmeebi?* | Здорово, брат! Как дела / как движ? | Универсальное дружелюбное приветствие на улице или в компании |
| | მე [Имя] მქვია, შენ? | *me [Имя] mkvia, shen?* | Меня зовут [Имя], а тебя? | **მე გიორგი მქვია, შენ?** (*me Giorgi mkvia, shen?* — Меня Гиорги зовут, а тебя?) |
| | საიდან ხარ, რა რაიონიდან? | *saidan khar, ra raionidan?* | Откуда сам / с какого района? | Классический вопрос для завязки разговора с местными пацанами |
| | აბა, რა ხდება აქ? | *aba, ra khdeba ak?* | Ну чё, какой тут движ происходит? | Отлично подходит, когда только подтянулся в новую компанию |
| **Застолье (Суфра)** | გაუმარჯოს! / გაგიმარჯოს! | *gaumarjos! / gagimarjos!* | За...! (Да здравствует!) / И тебе здравствовать! | Базовая связка для любого тоста и ответа при чокании |
| | ჩვენს შეხვედრას გაუმარჯოს! | *chvens shekhvedras gaumarjos!* | За нашу встречу! | Первый классический тост, когда собрались за столом |
| | ჩვენს ძმობას და მეგობრობას გაუმარჯოს! | *chvens dzmobas da megobrobas gaumarjos!* | За наше братство и дружбу! | Главный пацанский тост за столом |
| | კაცობას და გაგებას გაუმარჯოს! | *katsobas da gagebas gaumarjos!* | За мужество/человечность и взаимопонимание! | Тост с весом, где **გაგება** (*gageba*) — «понимание по жизни» |
| | მშობლებს გაუმარჯოს! | *mshoblebs gaumarjos!* | За родителей! | Святой тост, обычно пьётся стоя и до дна |
| | წასულების ხსოვნა იყოს! | *tsasulebis khsovna iqos!* | Светлая память ушедшим! | **Важно:** на этом тосте не чокаются! |
| | ალავერდი შენთან ვარ | *alaverdi shentan var* | Передаю тебе слово (продолжить тост) | Когда тамада говорит это тебе, нужно подхватить его мысль парой фраз и выпить |
| | ბოლომდე! | *bolomde!* | До дна! | მოდი, ეს სადღეგრძელო **ბოლომდე** დავლიოთ (*modi, es sadghegrdzelo bolomde davliot* — Давай выпьем этот тост до дна) |
| | გადაიღე | *gadaighe* | Накладывай / бери еду | ხინკალი ცხელია, **გადაიღე** (*khinkali tskhelia, gadaighe* — Хинкали горячие, накладывай) |
| | აღარ შემიძლია, გავსკდი | *aghar shemidzlia, gavskdi* | Больше не могу, я лопнул | Шутливый способ отбиться от очередной порции еды за столом |
