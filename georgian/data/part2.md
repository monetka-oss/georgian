# Шпаргалка по живому грузинскому языку (Часть 2)

Вторая часть нашей базы: фразы-выручалки для выигрыша времени в диалоге, короткие «кирпичики» для быстрой речи, грамматика сложных предложений, глаголы положения в пространстве и уличный сленг.

| Категория | Выражение / Слово | Транскрипция | Перевод / Смысл | Пример использования / Контекст |
| :--- | :--- | :--- | :--- | :--- |
| **Фразы-буферы (выиграть время)** | მოიცა, ერთი წამი... | *moitsa, erti tsami...* | Погоди, секунду... | Главный тормоз, чтобы дать мозгу пару секунд подумать перед ответом |
| | ერთი წუთით, ვფიქრობ... | *erti tsutit, vpikhrob...* | Секунду, я думаю... | Используй, когда нужно сформулировать мысль |
| | რა ჰქვია... / როგორ არის... | *ra hkvia... / rogor aris...* | Как это называется... / Как же это... | Выручает, если забыл слово прямо посреди предложения |
| | კარგი კითხვაა... | *kargi kitkhvaa...* | Хороший вопрос... | Даёт паузу, даже если вопрос застал врасплох |
| | მართალი გითხრა, არ ვიცი ზუსტად... | *martali gitkhra, ar vitsi zustad...* | Честно говоря, я точно не знаю... | Отличный способ мягко съехать, если не знаешь ответа |
| | საინტერესოა... | *sainteresoa...* | Интересно... | Реакция с паузой на неожиданную инфу |
| | ვერ გავიგე, რა თქვი? | *ver gavige, ra tkvi?* | Я не понял, что ты сказал? | Прямой и естественный переспрос |
| | აი, თავიდან თქვი რა? | *ai, tavidan tkvi ra?* | Эй, скажи с начала, а? | Разговорный уличный вариант попросить повторить |
| | მოიცა, ვერ მივხვდი | *moitsa, ver mivkhvdi* | Погоди, я не въехал / не догнал | Когда собеседник слишком быстро накидал инфы |
| **Короткие «кирпичики»** | მაღაზიაში მივდივარ | *maghaziashi mivdivar* | В магазин иду | Пример речи без сложных оборотов: сущность + действие |
| | პური მინდა | *puri minda* | Хлеб хочу | **ყავა მინდა** (*qava minda* — кофе хочу) / **ეს მინდა** (*es minda* — это хочу) |
| | დრო არ მაქვს | *dro ar makvs* | Времени нет | Короткий отказ или объяснение спешки |
| | რა ღირს? | *ra ghirs?* | Сколько стоит? | **ეს რა ღირს?** (*es ra ghirs?* — сколько это стоит?) |
| | სად არის? | *sad aris?* | Где находится? | **აქ არის?** (*ak aris?* — это здесь?) |
| | ცოტა ხანი | *tsota khani* | Чуть-чуть / немного времени | **ცოტა ხანი მოიცა** (*tsota khani moitsa* — погоди немного) |
| | მალე მოვალ | *male moval* | Скоро приду / вернусь | Кидаешь, когда отходишь ненадолго |
| | ვეღარ ვხვდები | *veghar vkhvdebi* | Больше не понимаю / не догоняю | Когда объясняют слишком запутанно |
| | ანუ | *anu* | То есть / короче | Слово-связка, чтобы переформулировать мысль, если запутался |
| **Сложные предложения (Союзы)** | რომ (в речи — რო) | *rom (ro)* | Что / чтобы / когда / если | **ვიცი, რო მოხვალ** (*vitsi, ro mokhval* — знаю, что придёшь); **სახლში რო მიხვალ, დამირეკე** (*...когда придёшь, позвони*) |
| | ვინც | *vints* | Кто / который (про людей) | **ის ბიჭი, ვინც გუშინ ვნახეთ** (*is bichi, vints gushin vnakhet* — тот парень, которого мы вчера видели) |
| | რომელიც (რომელი) | *romelits (romeli)* | Который (про предметы) | **ბურთი, რომელიც იქ დევს** (*burti, romelits ik devs* — мяч, который там лежит) |
| | რაც | *rats* | То, что / всё, что | **ყველაფერი, რაც გითხარი, სიმართლეა** (*qvelaperi, rats gitkhari, simartlea* — всё, что я сказал — правда) |
| | სადაც | *sadats* | Где / куда | **იმ ადგილას, სადაც ვცხოვრობ** (*im adgilas, sadats vtskhovrob* — в том месте, где я живу) |
| | როცა | *rotsa* | Когда | **როცა მოიცლი, მომწერე** (*rotsa moitsli, momtsere* — когда освободишься, напиши) |
| | იმიტომ, რომ (იმიტო რო) | *imitom, rom (imito ro)* | Потому что | **არ მოვედი, იმიტო რო მეზარებოდა** (*ar movedi, imito ro mezareboda* — не пришёл, потому что лень было) |
| | ამიტომ | *amitom* | Поэтому | **საცობი იყო, ამიტომ დავაგვიანე** (*satsobi iqo, amitom davagviane* — была пробка, поэтому опоздал) |
| | თუმცა / სამაგიეროდ | *tumtsa / samagierod* | Хотя / зато | **შორია, სამაგიეროდ იაფია** (*shoria, samagierod iapia* — далеко, зато дёшево) |
| | თუ | *tu* | Если (реальное условие) | **თუ დრო გექნება, გამოიარე** (*tu dro gekneba, gamoiare* — если будет время, загляни) |
| | რომ ... -დი / -და | *rom ... -di / -da* | Если бы ... то бы (нереальное условие) | **შენს ადგილას რომ ვიყო, მაგას არ ვიზამდი** (*...если бы я был на твоём месте, не сделал бы*) |
| **Глаголы в пространстве** | დევს | *devs* | Лежит (предметы, круглое) | **ტელეფონი მაგიდაზე დევს** (*teleponi magidaze devs* — телефон лежит на столе; также про мяч, ключи) |
| | დგას | *dgas* | Стоит (на ножках, вертикальное) | **ბოთლი მაგიდაზე დგას** (*botli magidaze dgas* — бутылка стоит на столе; также про шкаф, дом, дерево) |
| | ზის | *zis* | Сидит (люди, животные) | **კაცი სკამზე ზის** (*katsi skamze zis* — мужчина сидит на стуле) |
| | წევს | *tsevs* | Лежит (люди, животные) | **ბიჭი ლოგინში წევს** (*bichi loginshi tsevs* — парень лежит в постели) |
| | კიდია | *kidia* | Висит | **ქურთუკი საკიდზე კიდია** (*kurtuki sakidze kidia* — куртка висит на вешалке) |
| **Сленг: Одобрение и движ** | თესლი | *tesli* | Офигенный, мощнейший, пушка (букв. «семя») | **ძაან თესლი მანქანაა** (*dzaan tesli mankanaa* — очень крутая тачка) |
| | მაგარი | *magari* | Крутой, мощный (букв. «твёрдый») | **მაგარი ტიპი** (*magari tipi* — крутой пацан) |
| | ასწორებს | *astsorebs* | Кайфово, качает, вставляет | **ძაან ასწორებს!** (*dzaan astsorebs!* — капец как кайфово!) |
| | ძველი ტიპი | *dzveli tipi* | Старожил, авторитетный чел в тусовке | Человек старой закалки, который шарит за уважение |
| | გახურებული | *gakhurebuli* | Раскалённый, в самом разгаре | **სიტუაცია გახურებულია** (*situatsia gakhurebulia* — ситуация накалена / движ в разгаре) |
| | გაგებული | *gagebuli* | Прошаренный, «в теме» по жизни | Человек с правильным пониманием |
| | ვაიმე! / ვაიმე დედა! | *vaime! / vaime deda!* | Офигеть! / Ой, мама! | Универсальная реакция на шок, дичь или удивление |
| **Сленг: Наглые и тупые типы** | თავხედი | *tavkhedi* | Наглый, борзый, беспардонный | **რა თავხედია ეს ტიპი!** (*ra tavkhedia es tipi!* — какой же он наглый!) |
| | პზიორი / გაპზიორებული | *pziori / gapziorebuli* | Понтовщик / зазвездившийся | **ნუ პზიორობ აქ** (*nu pziorob ak* — не понтуйся тут) |
| | გაბერილი | *gaberili* | Надутый от пафоса, с короной на голове | Про того, кто слишком много о себе мнит |
| | ტლუ | *tlu* | Тупой, деревянный, тяжело соображающий | **რა ტლუ ტიპია, ვერაფერს ხვდება** (*ra tlu tipia, verapers khvdeba* — какой же он тупой, ничего не догоняет) |
| | გაყინული | *gaqinuli* | Тормоз (букв. «замороженный») | Когда человек завис и смотрит стеклянным взглядом |
| | ცუდი პონტის ტიპი | *tsudi pontis tipi* | Мутный челик, тип с гнильцой | Человек, от которого можно ждать подвоха |
| | ძაღლი | *dzaghli* | Крыса, свинский поступок (букв. «собака») | Жёсткое презрительное слово, кидать только по делу |
| | ტვინი არ აქვს | *tvini ar akvs* | Мозгов нет | Короткая характеристика для того, кто творит дичь |
| | აზრზე არ არის | *azrze ar aris* | Вообще не в адеквате / не отдупляет | **სპეციალურად აკეთებს თუ აზრზე არ არის?** (*...специально делает или вообще не в теме?*) |
