# 🇬🇪 Уличный и разговорный грузинский: Респекты, Глаголы, Зал и Рынок

## 1. Уважение, похвала и респект ровному типу

| Грузинский | Транскрипция | Перевод / Смысл | Контекст применения |
| :--- | :--- | :--- | :--- |
| **ჯიგარი ხარ!** | *Jigari khar!* | Ты душа-человек! / Красавчик! | Высшая благодарность за помощь, подгон или правильный поступок. |
| **მაგარი ჯიგარია** | *Magari jigaria* | Он реально душевный / ровный тип | Когда обсуждаешь с третьим лицом достойного пацана. |
| **ჩემი ჯიგარი** | *Chemi jigari* | Мой брат / мой родной | Обращение к близкому корешу. |
| **საღოლ!** | *Saghol!* | Красавчик! / Уважуха! / Зачёт! | Чисто уличный, пацанский респект за чёткое действие или результат. |
| **ყოჩაღ!** | *Qochagh!* | Молодец! / Отлично! | Более классическая похвала (подходит и для старших, и для друзей). |
| **აი, ეს მესმის!** | *Ai, es mesmis!* | Вот это я понимаю! / По-нашему! | Реакция на дельную идею или крутой поступок. |
| **ნამდვილი კაცია** | *Namdvili katsia* | Настоящий мужик / человек слова | Подчеркнуть авторитет и надежность. |
| **სიტყვის პატრონია** | *Sitqvis patronia* | Хозяин своего слова | Про того, кто отвечает за базар. |
| **მაგარი ვაჟკაცია** | *Magari vazhkatsia* | Реальный джигит / достойный парень | Уважительная оценка характера. |
| **ასწორებს!** | *Astsorebs!* | Кайфово! / Круто! | Одобрение ситуации, вещи или действия. |
| **თესლია!** | *Teslia!* | Пушка! / Лютая вещь! | Жёсткий уличный сленг для высшего восторга (про вещь, тачку, очки). |

## 3. Логика приставок: Направление и адресат

### Пространственные приставки (Превербы) на примере помощи
| Слово | Транскрипция | Перевод | Суть приставки |
| :--- | :--- | :--- | :--- |
| **დამეხმარე** | *damekhmare* | Помоги мне (вообще) | **და-** — законченное, полноценное действие. |
| **მომეხმარე** | *momekhmare* | Помоги мне (подойди сюда) | **მო-** — вектор действия направлен **к говорящему**. |
| **წამახმარე** | *tsamakhmare* | Чуть подтолкни / подсоби | **წა-** — легкое усилие, сдвинуть с мертвой точки (идеально для жима). |

### Двухсубъектные глаголы (Кто ➔ Кому)
* **მ-** в начале = действие направлено **на меня** (*мне / меня*).
* **გ-** в начале = действие направлено **на тебя** (*тебе / тебя*).

| Форма | Транскрипция | Перевод | Ситуация |
| :--- | :--- | :--- | :--- |
| **მითხარი** | *mitkhari* | Скажи мне | Просьба / требование объяснить. |
| **გითხარი** | *gitkhari* | Я сказал тебе | **ხომ გითხარი!** — *Я же тебе говорил!* |
| **გისმენ** | *gismen* | Слушаю тебя | Главная фраза, когда берешь трубку телефона, или «я весь во внимании». |
| **მისმენ?** | *mismen?* | Ты меня слушаешь? | Проверка, не отвлекся ли собеседник. |
| **ყველა ყური ვარ** | *qvela quri var* | Я — все уши | Разговорный аналог «весь во внимании». |

### Отглагольные существительные (Чит-код)
* **სი- + корень + -ე:** *ცოდნა* (знать) ➔ **სიცოდნე** (знания).
* **Суффиксы -ი / -ობა:** *ვარჯიშობს* (тренируется) ➔ **ვარჯიში** (тренировка); *სწავლობს* (учится) ➔ **სწავლა** (учеба).

## 5. Рынок, покупки и очки по образцу

| Фраза | Транскрипция | Перевод / Как использовать |
| :--- | :--- | :--- |
| **აი, ზუსტად მასეთი მინდა!** | *Ai, zustad maseti minda!* | Вот, точно такой же хочу! (Показывая образец друга). |
| **იმენა ეგეთი მინდა** | *Imena egeti minda* | Хочу именно такой (уличный акцент). |
| **უფრო მუქი / უფრო ღია აქვთ?** | *Ufro muki / ufro ghia akvt?* | Есть потемнее / посветлее? |
| **სახეზე როგორ მიჯდება?** | *Sakheze rogor mijdeba?* | Как они мне на лицо садятся? |
| **ცოტა დააკელი, ძმაო** | *Tsota daakeli, dzmao* | Скинь немного цену, брат (главная фраза для торга). |
| **ბოლო ფასი რა არის?** | *Bolo fasi ra aris?* | Какая окончательная цена? |
| **არ მაწყობს** | *Ar matsqobs* | Меня не устраивает. |

## 6. Реакции на удивление и споры

| Фраза | Транскрипция | Реальный смысл в базаре |
| :--- | :--- | :--- |
| **რას მელაპარაკები?!** | *Ras melaparakebi?!* | Да ладно?! / Ты серьезно?! / Да ты гонишь! (Удивление от новости). |
| **რას ამბობ?!** | *Ras ambob?!* | Что ты говоришь?! / Да ты что?! (То же самое, очень частое). |
| **რას ლაპარაკობ, კაი ტიპია!** | *Ras laparakob, kai tipia!* | О чём ты говоришь, он ровный тип! (Когда впрягаешься за кореша). |
| **ტყუილად ლაპარაკობ** | *Tquilad laparakob* | Зря болтаешь / пустословишь. |
